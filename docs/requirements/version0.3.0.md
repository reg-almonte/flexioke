# Version 0.3.0: Introducing Playlists -- including Favorites.

## 1. Playlists
- Add a Playlists management inside Stem Studio: add, delete a playlist; edit and add or remove songs.
- Show playlists in Karaoke mode where user can 'queue' all the songs inside it either in order or in random.
- Queueing the whole playlist can still allow existing functionalities such as queue a single song, update the positions of songs inside the queue.
- Songs can be added to any existing playlist only once.
