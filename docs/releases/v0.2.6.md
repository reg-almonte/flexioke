# Release v0.2.6

## Scope
- **EPIC-0008: Synchronized Lyrics Calibration & Karaoke UX Enhancements**
  - **STORY-0024: In-Modal LRC Timestamp Calibration Toolbar** (`TASK-0054`)
    - Client-side pure JS parsing engine (`shiftLrcTimestamps` in `src/static/library_queue.js`) handling standard `[MM:SS.xx]` and 3-decimal `[MM:SS.xxx]` LRC timestamps.
    - Mathematical calculation with boundary clamping at `00:00.00` and rollover minute formatting.
    - Preserves metadata ID3 tags (`[ti:...]`, `[ar:...]`), empty lines, and plain text.
    - Interactive toolbar in `#lyrics-modal` (`src/static/index.html`) with quick preset buttons (`-0.5s`, `-0.1s`, `+0.1s`, `+0.5s`) and custom delta input with `Apply` action.
    - In-place DOM update with ephemeral status alert for 2.5 seconds.
  - **STORY-0025: Collapsible Karaoke Sidebar Accordions** (`TASK-0055`)
    - Collapsible card structure for Playback Queue (`#accordion-header-karaoke-queue`) and Song Library (`#accordion-header-karaoke-library`) in `#view-karaoke`.
    - Interactive chevron indicators with smooth rotation transitions (`rotate-180`).
    - Full keyboard accessibility with `role="button"` and `tabindex="0"`.
    - Persistent state stored in `localStorage['flexioke_karaoke_accordions']` across reloads and tab switches.
  - **STORY-0026: Smart Idle Stage Play Action & Empty Queue Fallback** (`TASK-0056`)
    - Smart play trigger wired to primary transport button (`#karaoke-play-btn`) and idle stage canvas (`#karaoke-lyrics-stage`) when `currentJob == null`.
    - Auto-plays the top queued song via `window.flexiokeQueue.playNext()` / `advanceNext(true)` when queue is populated.
    - Automatically opens `#song-catalog-modal` with auto-focused search when queue is empty.
    - Backwards-compatible `window.flexiokeSongLibrary` alias on `window.flexiokeLibrary`.

## Setup / Running This Release

### Prerequisites
- Python 3.9+ with virtual environment
- `ffmpeg` installed on system path
- Node.js (optional, for frontend syntax checks)

### Installation & Run
```bash
# Checkout release
git checkout v0.2.6

# Activate virtual environment
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Start backend server
uvicorn src.main:app --host 0.0.0.0 --port 8000 --reload
```

## Suggested Pre-Deployment Checklist
- [ ] Confirm browser local storage is accessible for accordion persistence.
- [ ] Verify `ffmpeg` is available on system `$PATH`.
- [ ] Confirm outbound network access for LRCLIB auto-fetching.
