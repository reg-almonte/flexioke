# Release v0.4.0

## Scope
- **EPIC-0011: Video Backgrounds, Stage Geometry Controls & Side A/B Uploads**
  - **STORY-0034: Looping Video Background Engine & Stage Synchronization** (`TASK-0071`, `TASK-0072`)
    - Video store manager with directory auto-discovery in `./data/videos/` supporting `.mp4`, `.webm`, `.mov`, and `.mkv` files.
    - REST endpoints: `GET /api/videos` (list discovered videos), `POST /api/videos/upload` (multipart video upload with format validation), and `GET /api/videos/{filename}` (HTTP 206 Partial Content range requests and full video streaming).
    - Per-song video assignment (`video_id`) and start offset (`video_offset_seconds`) stored on `JobRecord`, editable in Song Details modal, and propagated through playback queue.
    - Layered HTML5 video renderer (`<video id="karaoke-bg-video">`) mounted inside `#karaoke-stage-card` with `pointer-events-none`, `muted`, `loop`, `playsinline`, and `opacity-40` backdrop styling behind floating glassmorphism lyrics.
    - Lockstep timecode synchronization: `video.currentTime = (audioTime + videoOffset) % videoDuration` across play, pause, seek, and loop operations, with clean unloading on track end or player reset.
  - **STORY-0035: Fullscreen Stage Geometry Customization** (`TASK-0073`)
    - Interactive range sliders in `#karaoke-settings-modal` for Fullscreen Stage Width (`60%`–`100%`, default `98%`), Height (`30vh`–`80vh`, default `56vh`), and Vertical Center Offset (`-20%`–`+20%`, default `0%`).
    - Dynamic CSS custom properties (`--karaoke-fullscreen-stage-width`, `--karaoke-fullscreen-stage-max-height`, `--karaoke-fullscreen-stage-v-offset`) scoped strictly to `#karaoke-stage-card:fullscreen` and `.stage-fullscreen` without impacting windowed desktop card layout.
    - Persistent geometry preferences stored in `localStorage` (`flexioke_stage_config`) with instant reset to defaults.
  - **STORY-0036: Direct Side A / Side B Dual-Track Ingestion & Vocal Hot-Swapping** (`TASK-0074`, `TASK-0075`)
    - Direct dual-track ingestion endpoint `POST /api/jobs/upload-side-ab` for pre-separated studio audio files (Side B instrumental + optional Side A vocal version) creating instant completed jobs (`status: completed`, `progress: 100%`) bypassing AI stem separation workers.
    - In-modal attachment endpoint `POST /api/jobs/{id}/attach-side-a` allowing vocal tracks to be attached to existing Side B songs.
    - Dedicated Stem Studio dual-dropzone upload tab and `Side A/B` badges across Song Library, Playlists, and Song Catalog modal.
    - Dual-stream WebAudio playback coordinator with instantaneous, click-free vocal hot-swapping between Side A (full mix) and Side B (instrumental) via the Lead Vocal button.
    - Mutex muting support (total silence when both stems are muted in Stem Studio) and adaptive button states for single-sided tracks (`Lead: OFF (Side B Only)`, `Backing: N/A (Side A/B)`).

## Setup / Running This Release

### Prerequisites
- Python 3.9+ with virtual environment
- `ffmpeg` installed on system path
- `./data/videos/` directory populated with at least one background video (`bg001.mp4`)

### Installation & Run
```bash
# Checkout release tag
git checkout v0.4.0

# Activate virtual environment
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Start backend server
uvicorn src.main:app --host 0.0.0.0 --port 8000 --reload
```

## Suggested Pre-Deployment Checklist
- [ ] Confirm `./data/videos` directory exists with write permissions and contains `bg001.mp4`.
- [ ] Confirm browser local storage is accessible for stage geometry persistence (`flexioke_stage_config`).
- [ ] Verify `ffmpeg` is available on system `$PATH`.
- [ ] Confirm outbound network access for LRCLIB auto-fetching.
