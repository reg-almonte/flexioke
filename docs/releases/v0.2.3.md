# Release v0.2.3

## Scope
- **EPIC-0005: Karaoke Stage UX Refinements, Intro Splash & Song Catalog Modal**
  - **STORY-0014: Intro Splash Overlay & Configurable Countdown Threshold** (`TASK-0033`, `TASK-0034`)
    - Animated Title & Artist Intro Splash overlay with synchronized stem pre-buffering delay.
    - Configurable Intro Splash Duration setting ($0–5$s, default 3s) in Stage Settings.
    - Configurable Countdown Gap Threshold setting ($3–5$s, default 3s) in Stage Settings.
  - **STORY-0015: Stage Restart Lyrics/Highlight Reset & Dual Highlight Color Customization** (`TASK-0035`, `TASK-0036`)
    - Atomic lyrics stage scroll-to-top (`scrollTop = 0`) and active highlight reset upon track restart.
    - Global keyboard shortcuts: `R` / `Home` for Restart (with input/textarea focus guard), `Esc` for modal/fullscreen dismissal.
    - Dual Highlight Color pickers in Stage Settings: Highlight Glow & Border Color (`--karaoke-highlight-color`) and Highlight Fill & Background Color (`--karaoke-highlight-fill`) with live DOM updates and persistence.
  - **STORY-0016: Fixed-Height Sidebar Viewports, Scoped Permissions & Song Catalog Modal** (`TASK-0037`, `TASK-0038`, `TASK-0039`)
    - Fixed 3-card height viewport for Playback Queue (`h-[196px]`) with centered non-collapsing empty state.
    - Compact 3-card height viewport for Song Library (`h-[210px]`).
    - Removed redundant `"Stems ready"` text from library song cards.
    - Scoped "Edit Details / Lyrics" button (`📝`) strictly to Stem Studio, omitting it from Karaoke Mode and Catalog Modal.
    - Full-Screen Song Catalog Modal (`#song-catalog-modal`) with real-time search, quick-clear (`✕`), 4-way sorting (`Title A-Z/Z-A`, `Artist A-Z`, `Recent`), and 1-click `▶ Play Now` & `➕ Add to Queue` actions.
  - **BUG-0004: Visual Countdown Cue Triggering During Active Sung Lyrics**
    - Corrected countdown cue evaluation to trigger strictly during long song intros and explicit empty non-lyric breaks (`isInstrumental` / empty lines), eliminating cue interruptions during active singing.
  - **BUG-0005: Edit Details / Lyrics Button Missing in Stem Studio Song Library**
    - Corrected DOM view selector to `#view-stem-studio` and added explicit container IDs (`#studio-library-list`, `#karaoke-library-list`) ensuring the Edit button (`📝`) is rendered in Stem Studio while remaining omitted in Karaoke Mode.

## Setup / Running This Release

### Prerequisites
- Python 3.9+ with virtual environment
- `ffmpeg` installed and available on `PATH`
- PyTorch with MPS (Apple Silicon GPU) or CUDA acceleration

### Execution
```bash
# 1. Activate environment
source .venv/bin/activate

# 2. Start Uvicorn Server
PYTHONPATH=. uvicorn src.main:app --host 0.0.0.0 --port 8000 --reload
```
- Web Application: `http://localhost:8000`
- API Documentation: `http://localhost:8000/docs`

## Suggested Pre-Deployment Checklist
- [ ] Confirm GPU acceleration (`mps` / `cuda`) is detected properly.
- [ ] Verify `./data/` directories have appropriate disk write permissions.
- [ ] Confirm `flexioke_stage_config` localStorage schema upgrades gracefully on existing browser clients.
- [ ] Check firewall/security groups if exposing port 8000 externally.
