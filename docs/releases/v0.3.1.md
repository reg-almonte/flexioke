# Release v0.3.1

## Scope
- **EPIC-0010: UI & Stage Experience Enhancements**
  - **STORY-0031: In-Modal Song Navigation & Dirty Changes Guard** (`TASK-0065`, `TASK-0066`)
    - In-modal song navigation toolbar (`#modal-nav-prev-btn`, `#modal-nav-counter-badge`, `#modal-nav-next-btn`) in `#lyrics-modal` header with dynamic `Track X of Y` badge and boundary disabling.
    - Context-aware navigation state tracking across filtered Song Library, sorted Song Catalog modal, and custom playlist views.
    - Unsaved changes confirmation dialog (`window.confirm`) intercepting track navigation, close button, and `Escape` key when Title, Artist, or Lyrics inputs have unsaved modifications.
    - Keyboard navigation shortcuts (`Alt + Left Arrow`, `Alt + Right Arrow`) with input collision protection.
  - **STORY-0032: Centralized Modular SVG Icon Dictionary** (`TASK-0067`, `TASK-0068`)
    - Standalone zero-dependency module `src/static/icons.js` defining `window.flexiokeIcons` (30+ semantic keys) and helper `window.getIconHtml()`.
    - Comprehensive UI overhaul replacing emojis/Unicode glyphs with crisp high-DPI vector SVGs across multitrack transport bar, karaoke stage, modal controls, and stem channel headers.
    - Accessible tooltips with explicit keyboard shortcut cues (`Space`, `R`, `N`, `F`, `Alt+Left`, `Alt+Right`, `Esc`).
  - **STORY-0033: Immersive YouTube-Style Fullscreen Karaoke Stage** (`TASK-0069`, `TASK-0070`)
    - In-place `.karaoke-cinema-fullscreen` expanding the karaoke stage across the full viewport (`100vw × 100vh`) with a rich cinema backdrop (`#030712`).
    - Floating glassmorphism top header (`#karaoke-top-header`) and bottom transport bar (`#karaoke-transport-bar`) with `backdrop-filter: blur(16px)` and dedicated Exit button (`#karaoke-exit-fullscreen-btn`).
    - 3000ms inactivity auto-hide engine with mouse cursor suppression (`cursor: none`) during active fullscreen playback.
    - Immediate activity wake-up on mouse movement, touch events, or keyboard input.
    - Persistent visible controls when audio playback is paused or stopped.
    - Stage canvas double-click and global `F` keyboard shortcut toggles.

## Setup / Running This Release

### Prerequisites
- Python 3.9+ with virtual environment
- `ffmpeg` installed on system path
- Node.js (optional, for frontend syntax checks)

### Installation & Run
```bash
# Checkout release
git checkout v0.3.1

# Activate virtual environment
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Start backend server
uvicorn src.main:app --host 0.0.0.0 --port 8000 --reload
```

## Suggested Pre-Deployment Checklist
- [ ] Confirm `./data` directory has write permissions for atomic persistence.
- [ ] Confirm browser local storage is accessible for accordion persistence.
- [ ] Verify `ffmpeg` is available on system `$PATH`.
- [ ] Confirm outbound network access for LRCLIB auto-fetching.
