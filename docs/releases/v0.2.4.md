# Release v0.2.4

## Scope
- **EPIC-0006: Stem Studio Upgrade & Separation Job Queue**
  - **STORY-0017: Direct Audio URL Ingestion & Smart Title/Artist Parsing** (`TASK-0040`, `TASK-0041`)
    - Streaming direct audio URL downloader (`POST /api/jobs/download-url`) with MIME validation, magic-byte inspection, and real-time download progress tracking.
    - Smart filename & delimiter parsing engine (`parse_song_and_artist`) extracting clean Song Title and Artist metadata from various delimiter formats (`Artist - Title`, `Title by Artist`, track number prefixes, file extensions).
  - **STORY-0018: Multi-File Batch Ingestion & Asynchronous Separation FIFO Queue** (`TASK-0042`, `TASK-0043`)
    - Asynchronous single-worker FIFO separation executor queue (`ThreadPoolExecutor(max_workers=1)`) with thread-safe `JobStatus.CANCELLED` state transitions and intermediate temp directory purging.
    - Drag-and-drop & multi-file batch upload dropzone (`#drop-zone`) accepting multiple audio files simultaneously.
    - Real-time separation queue monitor card with live `#1 in queue`, `#2 in queue` position badges and 1-click queued job cancellation.
  - **STORY-0019: Stem Studio Collapsible Accordions & Persistent Notes Scratchpad** (`TASK-0044`, `TASK-0045`)
    - Collapsible sidebar accordion cards (`#studio-card-add-song`, `#studio-card-library`, `#studio-card-queue`) with animated chevron indicators and `localStorage['flexioke_studio_accordions']` persistence.
    - Persistent Studio Notes scratchpad modal (`#studio-notes-modal`) accessible from top header with real-time auto-saving (`localStorage['flexioke_studio_notes']`), save indicator feedback, and programmatic safe DOM parsing of clickable HTTP/HTTPS links.
  - **STORY-0020: Expanded Studio Song Catalog Modal & Default Recent Sort** (`TASK-0046`, `TASK-0047`)
    - Full-Screen Song Catalog Modal trigger (`#open-studio-catalog-btn`, `⛶`) integrated into the Stem Studio library accordion header.
    - Context-aware library default sorting: Stem Studio defaults to **Recently Added** (descending by `created_at`), while Karaoke Mode preserves alphabetical **Title (A-Z)** sorting.
    - `📝 Edit` action on catalog cards opening Song Details & LRC Editor modal with z-index stacking.
  - **STORY-0021: Combined Stem Zip Export, Track Deletion & Post-Processing Archiving** (`TASK-0048`, `TASK-0049`, `TASK-0050`)
    - Dynamic streaming stem `.zip` bundler endpoint (`GET /api/jobs/{job_id}/export/zip` and `/download-all.zip`) packaging 3 isolated stem MP3s (`instrumental.mp3`, `lead_vocals.mp3`, `backing_vocals.mp3`) and `lyrics.lrc` (if available) with 1-click buttons in Multitrack Player header, Catalog Modal cards, and Edit Details modal.
    - Permanent track deletion endpoint (`DELETE /api/jobs/{job_id}`) with confirmation prompt, cascading disk cleanup (`./data/jobs/{job_id}/`), archive purging, and playback queue cleanup.
    - Post-separation raw audio archiving pipeline moving original input files from `./data/jobs/{job_id}/` to `./data/archive/{job_id}_{filename}` upon Stage 2 completion.

## Setup / Running This Release

### Prerequisites
- Python 3.9+ with virtual environment
- `ffmpeg` installed on system path
- CPU or Apple Silicon MPS / NVIDIA CUDA for AI models

### Installation & Run
```bash
# Clone & checkout release tag
git checkout v0.2.4

# Activate virtual environment
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Start backend server
uvicorn src.main:app --host 0.0.0.0 --port 8000 --reload
```

## Suggested Pre-Deployment Checklist
- [ ] Confirm `./data/jobs` and `./data/archive` storage directories have sufficient disk space for stem models and output MP3s.
- [ ] Verify `ffmpeg` version 7.0+ is accessible in runtime `$PATH`.
- [ ] Ensure network security policies allow outbound HTTP/HTTPS requests to public audio URLs.
- [ ] Perform browser sanity check across Chrome/Firefox/Safari for WebAudio and Wavesurfer rendering.
