# Release v0.3.0

## Scope
- **EPIC-0009: Playlists Management & Favorites System**
  - **STORY-0027: Backend Playlist Store & REST API Services** (`TASK-0057`, `TASK-0058`)
    - Pydantic models `Playlist`, `PlaylistSummary`, `PlaylistDetail`, and `PlaylistFromQueueRequest` in `src/models.py`.
    - Thread-safe singleton `PlaylistManager` in `src/services/playlist_manager.py` with `threading.RLock()`, atomic file replacement (`./data/playlists.json.tmp.*` -> `./data/playlists.json`), and orphan auto-pruning.
    - Automatic initialization of immutable system `favorites` playlist on clean bootstrap.
    - 9 REST API endpoints under `/api/playlists` with duplicate prevention (409) and system playlist protection (400).
    - Cascading song deletion: `DELETE /api/jobs/{job_id}` prunes track references across all playlists.
  - **STORY-0028: Built-in Favorites System & 1-Click Heart Toggles** (`TASK-0059`, `TASK-0060`)
    - Reactive client state machine `FavoritesManager` in `src/static/playlists.js` with `window.flexiokeFavoritesSet`.
    - Optimistic UI updates with automatic rollback on network errors.
    - 1-click Heart toggle buttons rendered across Stem Studio library cards, Karaoke Mode library cards, and Song Catalog modal rows with `e.stopPropagation()` event isolation.
    - Global DOM event bus synchronization (`flexioke:favorites-toggled`, `flexioke:favorites-loaded`, `flexioke:job-deleted`).
  - **STORY-0029: Stem Studio Playlists Management UI & Song Modal Assignment** (`TASK-0061`, `TASK-0062`)
    - Collapsible `#studio-card-playlists` accordion in Stem Studio sidebar.
    - Playlists Directory and Detail/Editor views with live in-playlist search filter, track index numbering, sequential `➕ Queue All`, ▲/▼ reordering, and ✕ song removal.
    - Multi-playlist checkbox assignment group inside `#lyrics-modal` (`#lyrics-modal-playlists-container`) with live 2.5s feedback indicator.
  - **STORY-0030: Karaoke Mode Playlist Ingestion, 3-Way Queue Dispatch & Queue Saving** (`TASK-0063`, `TASK-0064`)
    - Collapsible `#karaoke-card-playlists` accordion in Karaoke Mode sidebar with `localStorage` persistence.
    - 3-way queue dispatch engine (`➕ In Order`, `🔀 Shuffle` via Fisher-Yates algorithm, and `▶ Play Now` replace and start).
    - Queue-to-Playlist conversion feature with `💾 Save` buttons on queue card headers in both views and dynamic disabled state management via `flexioke:queue-updated`.

## Setup / Running This Release

### Prerequisites
- Python 3.9+ with virtual environment
- `ffmpeg` installed on system path
- Node.js (optional, for frontend syntax checks)

### Installation & Run
```bash
# Checkout release
git checkout v0.3.0

# Activate virtual environment
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Start backend server
uvicorn src.main:app --host 0.0.0.0 --port 8000 --reload
```

## Suggested Pre-Deployment Checklist
- [ ] Confirm `./data` directory has write permissions for atomic `playlists.json` persistence.
- [ ] Confirm browser local storage is accessible for accordion persistence.
- [ ] Verify `ffmpeg` is available on system `$PATH`.
- [ ] Confirm outbound network access for LRCLIB auto-fetching.
