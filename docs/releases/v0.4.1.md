# Release v0.4.1

## Scope
- **EPIC-0012: Code Quality, Performance Assessment & Test Suite Reorganization**
  - **STORY-0037: Domain-Tiered Test Suite Reorganization & Pytest Invariance** (`TASK-0076`, `TASK-0077`)
    - Migrated 42 flat test files from `tests/` into 4 structured functional subdirectories: `tests/api/` (12 suites, 50 tests), `tests/services/` (12 suites, 55 tests), `tests/frontend/` (16 suites, 82 tests), and `tests/integration/` (3 suites, 10 tests).
    - Added package marker `__init__.py` files across all test subdirectories.
    - Configured `pytest.ini` with `testpaths = tests` and `pythonpath = .` ensuring 100% root discovery invariance and single-command regression test execution.
    - Standardized relative asset resolution in Node.js DOM headless simulations (`test_svg_icons.py`, `test_karaoke_cinema_fullscreen.py`) to resolve from repository root.
  - **STORY-0038: 7-Dimensional Code Quality, Security & Performance Assessment** (`TASK-0078`, `TASK-0079`)
    - Conducted exhaustive technical audit of all backend services, API routes, models, and frontend SPA modules across 7 dimensions: Architecture Fit, Maintainability, Reliability, Efficiency, Testability, Consistency, and Readability.
    - Published formal report at `tests/ASSESSMENT_REPORT.md` featuring an Executive Scorecard with an Overall Quality Index of **8.9 / 10.0 (Grade: A-)**, concrete metrics on 9,286 source lines, concurrency locks, and atomic file replacement durability analysis.
  - **STORY-0039: Architectural Refactoring Roadmap & Technical Debt Plan** (`TASK-0080`)
    - Synthesized assessment report findings into an actionable phased refactoring roadmap at `docs/design/REFACTORING_ROADMAP.md`.
    - Established prioritized technical debt backlog: REF-01 (API Router decomposition), REF-02 (Frontend module decomposition), REF-03 (Zero-dependency event bus), REF-04 (Parameter aliasing), REF-05 (Server-Sent Events for job progress), and REF-06 (Unified client-side state store).
    - Formulated 5-point Step-by-Step Implementation & Verification Protocol ensuring 100% backward compatibility and zero regressions throughout future refactoring milestones.

## Setup / Running This Release

### Prerequisites
- Python 3.9+ with virtual environment
- `ffmpeg` installed on system path
- Node.js (for headless DOM simulation test runs)

### Installation & Run
```bash
# Checkout release tag
git checkout v0.4.1

# Activate virtual environment
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Run full test suite across all 4 domain tiers
pytest

# Start backend server
uvicorn src.main:app --host 0.0.0.0 --port 8000 --reload
```
