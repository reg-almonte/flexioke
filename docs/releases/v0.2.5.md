# Release v0.2.5

## Scope
- **EPIC-0007: Automated LRCLIB Synchronized Lyrics Integration**
  - **STORY-0022: LRCLIB Client Service & Background Separation Pipeline Auto-Sync** (`TASK-0051`, `TASK-0052`)
    - In-process HTTP client (`LRCLIBClient` in `src/services/lrclib_client.py`) utilizing standard `urllib` and `ssl` with `certifi` CA validation.
    - Standardized `User-Agent: Flexioke/0.2.5 (https://github.com/reg-almonte/flexioke)` and 5.0-second timeout.
    - Automatic exact match (`GET /api/get`) lookup with fallback to fuzzy candidate search (`GET /api/search`).
    - REST proxy endpoints `GET /api/lyrics/lrclib/get` (with title/artist/duration params) and `GET /api/lyrics/lrclib/search` in `src/api/routes.py`.
    - Automated background lyrics auto-sync during separation pipeline in `src/services/pipeline.py` persisting `lyrics.lrc` upon ingestion without blocking or failing stem separation.
  - **STORY-0023: Interactive 1-Click LRCLIB Lyrics Auto-Fetch in Lyrics Modal** (`TASK-0053`)
    - `⚡ Auto-Fetch LRC` toolbar in Song Details & Lyrics modal (`#lyrics-modal`) in `src/static/index.html`.
    - Real-time client-side asynchronous retrieval (`handleFetchLrclib` in `src/static/library_queue.js`) querying the proxy endpoint using the modal's active Title/Artist inputs.
    - In-modal status feedback alert (`#lrclib-fetch-alert`) rendering loading spinner (`⏳ Fetching...`), green success alert, amber no-match warning, and red error states.
    - Directly populates `#lyrics-textarea` allowing immediate preview, manual editing, and persistent saving (`💾 Save Changes`).
  - **Smart Filename Delimiter Parser Alignment:**
    - Aligned delimiter parsing with the standard `<Artist> - <Song Title>.<ext>` convention in `src/services/audio_validator.py`.

## Setup / Running This Release

### Prerequisites
- Python 3.9+ with virtual environment
- `ffmpeg` installed on system path
- CPU or Apple Silicon MPS / NVIDIA CUDA for AI separation

### Installation & Run
```bash
# Checkout release
git checkout v0.2.5

# Activate virtual environment
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Start backend server
uvicorn src.main:app --host 0.0.0.0 --port 8000 --reload
```

## Suggested Pre-Deployment Checklist
- [ ] Confirm outbound HTTPS access to `https://lrclib.net` is allowed by host network firewall.
- [ ] Verify `ffmpeg` is available on system `$PATH`.
