## Setup / Running This Release
1. **Prerequisites:** Python 3.9+ with virtual environment (`.venv`).
2. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
3. **Start Application Server:**
   ```bash
   PYTHONPATH=. uvicorn src.main:app --host 0.0.0.0 --port 8000
   ```
4. **Access Web App:** [http://localhost:8000](http://localhost:8000)

## Suggested Pre-Deployment Checklist
- [ ] **Hardware Acceleration:** Ensure production environment has CUDA/GPU or Apple Silicon MPS support for optimal inference throughput.
- [ ] **Storage Retention:** Ensure `./data/jobs` has adequate disk space for processed WAV stems and final 320kbps MP3s.
- [ ] **Reverse Proxy & SSL:** Configure Nginx/Caddy with HTTPS and large client upload limits (`client_max_body_size 100M`).
- [ ] **Process Supervision:** Configure systemd unit or Docker container restart policy for production reliability.
