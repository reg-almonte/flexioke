# Release v0.2.2

## Scope
- **EPIC-0004: Karaoke Stage Transport, Queue Reordering & Responsive UI Refinements**
  - **STORY-0011: Simultaneous Stage Header with CSS Marquee & Lyrics Stage Click-to-Play** (\`TASK-0026\`, \`TASK-0027\`)
    - Dual simultaneous stage header displaying *"Now Singing: [Title] - [Artist]"* on the left and *"Up Next: [Next Title] - [Next Artist]"* aligned to the right.
    - Continuous CSS marquee text scrolling for overflowing titles with \`ResizeObserver\` adaptive cutoff detection.
    - Full-stage click-to-play / pause toggle on the lyrics background with bounded lyric pill click isolation.
    - Atomic \`seekTo(timestamp)\` synchronization across all active audio stems avoiding circular seek feedback loops.
    - Clean terminal timestamp labeling (\`• End •\`) in LRC parser.
  - **STORY-0012: Modernized Karaoke Stage Bottom Transport Bar & Interactive Timecode** (\`TASK-0028\`, \`TASK-0029\`)
    - Master bottom transport cluster with Play/Pause, expanding YouTube-style hover volume slider (0–100%), and interactive timecode badge.
    - Click-toggleable timecode modes: Elapsed (\`00:00 / 03:45\`) vs Remaining (\`-03:45 / 03:45\`), persisted in \`localStorage\`.
    - Dedicated "Restart Song" button (🔄) with phase-locked zero-drift align to \`0.00s\`.
    - Compact icon-only vocal toggle buttons in default view (\`🎤\`, \`👥\`) that expand to detailed status pills in Fullscreen mode.
    - Refined Fullscreen Expand (\`⛶\`) and Collapse (\`↙\`) view controls.
    - Stage Settings modal (\`⚙\`) with real-time sliders for Base Lyric Font Size (\`14px\`–\`28px\`), Highlighted Lyric Font Size (\`16px\`–\`28px\`), and custom glow color picker.
  - **STORY-0013: Queue Reordering API, Sidebar Reorganization & Auto-Hiding Navbar** (\`TASK-0030\`, \`TASK-0031\`, \`TASK-0032\`)
    - Backend atomic \`POST /api/queue/reorder\` endpoint supporting index swap operations under threading locks.
    - Reorganized Karaoke sidebar layout placing Playback Queue above Song Library.
    - Live directional reordering buttons (\`▲\` / \`▼\`) on queue items with instant Up Next stage header synchronization.
    - Dynamic queue song counter badge (\`.queue-count-badge\`) displaying \`N songs\`.
    - Quick-clear \`✕\` button on search inputs in both views for instant search reset.
    - 3-Way Playback Interruption confirmation modal: \`Cancel\`, \`➕ Add to Queue\`, and \`▶ Play Now\`.
    - Auto-hiding top application navbar with smooth height/margin transitions and viewport hover reveal sensor.

## Setup / Running This Release

### Prerequisites
- Python 3.9+ with virtual environment
- \`ffmpeg\` installed and available on \`PATH\`
- PyTorch with MPS (Apple Silicon GPU) or CUDA acceleration

### Execution
\`\`\`bash
# 1. Activate environment
source .venv/bin/activate

# 2. Start Uvicorn Server
PYTHONPATH=. uvicorn src.main:app --host 0.0.0.0 --port 8000
\`\`\`
- Web Application: \`http://localhost:8000\`
- API Documentation: \`http://localhost:8000/docs\`

## Suggested Pre-Deployment Checklist
- [ ] Confirm GPU acceleration (\`mps\` / \`cuda\`) is detected properly.
- [ ] Verify \`./data/\` directories have appropriate disk write permissions.
- [ ] Check firewall/security groups if exposing port 8000 externally.
- [ ] Verify browser \`localStorage\` compatibility across client devices.
