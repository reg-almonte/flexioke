# Release v0.2.1

## Scope
- **EPIC-0003: Karaoke Mode Enhancements & Metadata Separation**
  - **STORY-0008: Backend Song Metadata Model, Persistence & Patch API** (`TASK-0019`, `TASK-0020`)
    - Extended `JobRecord` with explicit optional `artist: Optional[str]` field.
    - Zero-friction backwards compatibility for existing `jobs.json` files without artist data.
    - Added `PATCH /api/jobs/{job_id}` endpoint to update song title and artist metadata with automatic job list persistence.
  - **STORY-0009: Song Details & Lyrics Editor Modal & Dual-Field Search** (`TASK-0021`, `TASK-0022`)
    - Redesigned `#lyrics-modal` into a unified "Edit Song Details & Lyrics" interface.
    - Atomic client save workflow updating metadata via `PATCH` and LRC lyrics via `POST /api/jobs/{id}/lyrics`.
    - Enhanced library cards with bold Title and Artist subtitle (`Unknown Artist` fallback).
    - Multi-field library search (by title or artist) with case-insensitive auto-sorting by song title.
  - **STORY-0010: Dynamic Karaoke Stage Header, Countdown Cues & Customization Controls** (`TASK-0023`, `TASK-0024`, `TASK-0025`)
    - Alternating cross-fade stage banner cycling between `"Now Singing: [Title] • [Artist]"` and `"Up Next: [Next Title] • [Next Artist]"` on a configurable interval.
    - Remaining time countdown badge formatted alongside total duration (`MM:SS / MM:SS (-MM:SS)`).
    - Visual 3-beat countdown cue engine (`● ○ ○` -> `● ● ○` -> `● ● ●`) pulsing 3.0s prior to singing for intros and musical interludes (> 8.0s gap).
    - Real-time lyric font size scaling (`A-` / `A+` buttons).
    - Stage Settings modal (`⚙`) with persistent `localStorage['flexioke_stage_config']` controls for transition interval, active lyric glow color, and base font size.
    - Expanded / Fullscreen Mode (`⛶`) dynamically scales lyrics proportionally based on standard stage font settings.

## Setup / Running This Release

### Prerequisites
- Python 3.9+ with virtual environment
- `ffmpeg` installed and available on `PATH`
- PyTorch with MPS (Apple Silicon GPU) or CUDA acceleration

### Execution
```bash
# 1. Activate environment
source .venv/bin/activate

# 2. Start Uvicorn Server
PYTHONPATH=. uvicorn src.main:app --host 0.0.0.0 --port 8000
```
- Web Application: `http://localhost:8000`
- API Documentation: `http://localhost:8000/docs`

## Suggested Pre-Deployment Checklist
- [ ] Verify GPU acceleration (`mps` / `cuda`) is detected properly.
- [ ] Confirm `./data/` directories have appropriate disk write permissions.
- [ ] Check firewall/security groups if exposing port 8000 externally.
- [ ] Verify browser `localStorage` compatibility across client devices.
