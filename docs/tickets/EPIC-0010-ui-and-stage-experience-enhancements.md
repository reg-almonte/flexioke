# EPIC-0010: UI & Stage Experience Enhancements

## Summary
Delivers Version 0.3.1 improvements across three key areas:
1. In-Modal Song Navigation with Previous/Next controls, track position counters, and unsaved changes confirmation guards.
2. Centralized, high-DPI modular SVG icon dictionary with rich hotkey tooltips.
3. Immersive YouTube-style full-screen karaoke stage with floating translucent chrome, 3-second inactivity auto-hiding, cursor suppression, and double-click/hotkey stage triggers.
