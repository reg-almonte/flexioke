# EPIC-0005: Karaoke Stage UX Refinements, Intro Delay Engine & Song Catalog Modal

## Summary
Deliver essential stage UX enhancements and song catalog management for Flexioke Version 0.2.3. This includes a configurable Title & Artist Intro Splash screen with delayed audio start (0–5s), a configurable visual countdown cue threshold (3–5s, default 3s), atomic lyrics stage scroll-to-top and highlight reset on Restart Song, dual highlight color properties (glow border & fill tint), fixed 3-song height sidebar containers with badge cleanup, context-scoped edit button visibility (Stem Studio only), and a full-screen Expanded Song Catalog Modal with instant client-side search, sorting, and 1-click Play Now / Add to Queue actions.
