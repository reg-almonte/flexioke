# EPIC-0013: VS Code-Style Resizable Sidebar & Enhanced Karaoke UI

## Summary
Delivers Version 0.4.2 user experience enhancements comprising a VS Code-style 48px Activity Bar with live numeric count badges and full-height tabbed views for Playback Queue, Playlists, and Song Library, a draggable horizontal splitter divider with double-click reset and `Ctrl+B` collapse, a container-aware responsive stage with adaptive transport bar and prioritized controls, enlarged Fullscreen Cinema transport chrome (85% width, 26px high-DPI icons), and a universal focus-guarded Spacebar play/pause shortcut across Karaoke and Studio modes.
