# EPIC-0004: Karaoke Stage Transport, Queue Reordering & Responsive UI Refinements

## Summary
Deliver comprehensive UI and workflow refinements for Flexioke Karaoke Mode. This includes simultaneous dual stage headers ("Now Singing" on the left and "Up Next" on the right) with marquee text scrolling, event-delegated click-to-play on the stage background with bounded lyric pills, a modernized bottom transport bar with expanding YouTube-style hover volume control, restart action, click-toggleable timecode modes, queue reordering (up/down) with top position in the sidebar, and an auto-hiding application navbar.
