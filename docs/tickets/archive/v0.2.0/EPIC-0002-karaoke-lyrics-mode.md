# EPIC-0002: Synchronized Lyrics & Dedicated Karaoke Player Mode

## Summary
Deliver the complete Version 2 feature set enabling users to manage timestamped LRC lyrics, view a dedicated full-screen Karaoke stage with real-time synchronized line scrolling, switch seamlessly between Stem Studio and Karaoke Mode, control quick vocal toggles (Lead and Backing vocal mutes), and enjoy smart play interruption protection.
