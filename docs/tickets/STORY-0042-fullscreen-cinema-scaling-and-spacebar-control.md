# STORY-0042: Fullscreen Cinema Chrome Scaling & Universal Spacebar Control

## Parent Epic
- `docs/tickets/EPIC-0013-resizable-sidebar-activity-bar-and-karaoke-ui.md`

## What it delivers
Delivers an expansive, high-visibility Fullscreen Cinema mode with an 85% wide floating transport bar, 26px high-DPI icons, and enlarged typography for effortless 10-foot party viewing, alongside a universal focus-guarded Spacebar play/pause shortcut across Karaoke and Studio modes.

## Acceptance Criteria
- [ ] Fullscreen Cinema floating transport bar widens to 85% of screen width (max 1200px).
- [ ] High-DPI SVG icons scale up to 26px (`w-6.5 h-6.5`) with enlarged timecode and elevated vocal button padding.
- [ ] Dual stage header banners widen proportionally across the top in fullscreen mode.
- [ ] Universal Spacebar shortcut toggles Play/Pause in Karaoke and Studio modes without browser page scrolling jumps.
- [ ] Spacebar is strictly ignored when typing inside search inputs, textareas, notes, or rename fields.
