# EPIC-0003: Karaoke Mode Enhancements & Metadata Separation

## Summary
Deliver end-to-end enhancements for Flexioke Karaoke Mode and Song Management. This includes structured separation of Song Title and Artist metadata with zero-friction backwards-compatible migration, unified song details and lyrics editing, dual-field library search, dynamic alternating stage header ("Now Singing" ⟷ "Up Next") with remaining time countdown, visual countdown intro/interlude cues, and customizable stage styling settings.
