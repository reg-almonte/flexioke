# STORY-0032: Centralized Modular SVG Icon Dictionary

## Parent Epic
- `docs/tickets/EPIC-0010-ui-and-stage-experience-enhancements.md`

## What it delivers
Introduces a high-DPI, vector SVG icon dictionary that replaces emoji/Unicode character buttons across all player transport, stage controls, collapse chevrons, and Stem Studio channel tracks, providing accessible hotkey tooltips and modular customizability.

## Acceptance Criteria
- [x] Centralized SVG icon dictionary is modular and extensible in source code.
- [x] All transport controls (Play, Pause, Restart, Stop, Next, Volume), stage controls (Settings, Fullscreen, Chevrons), and stem channels use SVG icons.
- [x] Tooltips provide clear labels and keyboard shortcut hints.
- [x] 100% automated test coverage with zero regressions.
